# Citation Explorer

Paste a paper (title, DOI, arXiv ID, Google Scholar link, citation or BibTeX) and explore every paper that cites it, with abstracts, fields, topics and keywords. Export to CSV, RIS or BibTeX, send papers to Zotero, and use the literature-review tabs (Topics, Trends, Key papers, People, Screen, Report).

Data comes from OpenAlex, Crossref and Semantic Scholar over HTTPS. There are no trackers or analytics.

**Your keys stay in your browser.** Any API key you enter (OpenAlex, Semantic Scholar, Zotero) is used only from your own browser, is never sent to this site, and is not saved unless you tick "Remember keys".

Google Scholar results (via SerpApi) need the desktop version, because SerpApi can't be called directly from a website.
